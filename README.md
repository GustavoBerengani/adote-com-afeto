# Adote com Afeto

Site estático de uma galeria de adoção de animais, desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Galeria com animais disponíveis para adoção.
- Busca por nome, espécie, cidade ou perfil.
- Filtros por cães, gatos e cuidados especiais.
- Cards com detalhes do animal.
- Formulário demonstrativo de interesse em adoção.
- Layout responsivo para desktop e celular.

## Pilares do projeto

Os pilares não aparecem como uma seção explícita no site. Eles são demonstrados pelas escolhas de implementação:

- Excelência operacional: arquivos separados por responsabilidade.
- Segurança: formulário demonstrativo sem envio de dados sensíveis.
- Confiabilidade: funcionamento estático sem depender de banco de dados nesta versão.
- Eficiência de desempenho: JavaScript leve e imagens carregadas sob demanda.
- Otimização de custos: hospedagem estática simples antes da futura etapa em cloud.
- Sustentabilidade: baixa complexidade técnica e proposta social de adoção responsável.

## Como abrir

Abra o arquivo `index.html` diretamente no navegador.
